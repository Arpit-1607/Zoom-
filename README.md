# Zoom

A full-stack video conferencing web application that allows users to create and join video meetings with real-time audio and video communication.

## Features

- 🎥 Create and join video meetings
- 🎤 Real-time audio and video
- 💬 In-meeting communication
- 🔗 Share meeting links
- 👥 Multiple participants
- 🔐 User authentication
- 📱 Responsive interface
- 🖥️ Modern video conferencing UI
